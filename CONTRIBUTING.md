# Como contribuir

Contribuições entram por pull request. Antes de abrir um, rode os três comandos de prova descritos em `AGENTS.md`; todos precisam sair 0.

## Licença do projeto

O código está sob a Functional Source License 1.1 com licença futura Apache 2.0 (`LICENSE`). Você pode usar, estudar, modificar e contribuir; não pode usar o código para oferecer um produto ou serviço que concorra com este projeto. Cada versão passa a valer como Apache 2.0 dois anos depois de publicada.

## Acordo de contribuição

Ao enviar um pull request, você declara que:

1. escreveu a contribuição ou tem o direito de enviá-la;
2. concede ao mantenedor (Erick, github.com/startRED) uma licença perpétua, mundial, gratuita, irrevogável e não exclusiva para usar, modificar, sublicenciar e distribuir a contribuição sob quaisquer termos, inclusive comerciais e inclusive sob outra licença ou outro nome do projeto;
3. mantém os direitos autorais sobre o que escreveu.

Sem esse acordo o pull request não é aceito.
